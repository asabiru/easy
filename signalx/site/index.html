How it works

A 9-stage pipeline runs end-to-end on every news item we ingest. Each stage is independently testable and replaceable. The final signal is a structured object — not a free-form string — so it can drive automation downstream.

📰 Ingest→ 🧹 Normalize→ 🪪 Dedup→ 🏢 Company match→ 🏷️ Classify→ 📊 Impact + sentiment→ 📈 Market check→ 🛡️ Anti-fake→ ⚡ Signal engine→ 📡 Telegram + DB
⚡

What's in the box

Every module ships testable. No black-box ML — explicit rules you can read, tune, and audit.

🛡️

Anti-fake scoring

Account age, follower quality, linguistic markers, pre-news price action and cross-source confirmation feed a 0..100 fake_risk score. ≥50 SKIPs the signal automatically.

📊

Market-aware risk gate

Spread width, 5m volume from real OHLCV bars, late-entry detection. We won't fire LONG on an instrument that just ripped 4% in the last minute.

🔁

Cross-source confirmation

A 90-second sliding window across all sources. When 2+ independent sources confirm the same ticker+event, confidence boosts and fake_risk drops.

📡

Telegram-first delivery

Plain-text formatted messages — no HTML escaping bugs, every special character (<, >, &) renders as-is. Includes action, entry, SL, TP, risk, reason.

🪙

Energy sector coverage

XOM, CVX, COP, OXY, SHEL, BP, SLB, NEE, FSLR, ENPH plus OPEC / EIA / refinery-outage event rules. The full energy desk in one universe.

📈

Outcome tracking

Every signal is sampled at +1m / +3m / +5m / +15m. Win rate, latency p50/p95, fake_risk distribution exposed via /performance/summary.

Tradable universe
